# Тыквенный переполох

Мультяшная веб-аркада для короткого хэллоуинского турнира. Игрок управляет ведьмой мышью, пальцем или клавишами ← → / A D. Раунд длится 60 секунд, есть три жизни. Тыквы, конфеты и золотые тыквы дают очки; черепа и призраки отнимают жизнь. За серии удачных уловов начисляется бонус.

## Рейтинг

Общая таблица рекордов хранится в Cloudflare D1. При старте сервер создаёт одноразовый раунд; после завершения сохраняется лучший результат браузера. Имя игрок вводит самостоятельно. Для конкурса с реальными призами организатору стоит сверить победителя с сотрудником: входа через корпоративную учётную запись и полной защиты от подмены очков пока нет.

## Разработка

```text
npm ci
npm run db:generate
npm run build
npm run dev
```

Для локальной базы после сборки примените SQL из `drizzle/` командой Wrangler, описанной в `README.md` стартера Sites. Манифест `.openai/hosting.json` подключает D1 как `DB`; при публикации Sites применяет миграции.
