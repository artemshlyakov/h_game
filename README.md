# Ловец тыкв

Прототип хэллоуинской веб-игры на **TypeScript, Phaser и Vite**.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173`).

## GitHub Pages

GitHub Pages в этом репозитории публикует корень ветки `main`. Команда `npm run build` собирает игру и кладёт готовые `index.html` и `assets/` в корень репозитория. После изменений игры запустите сборку и добавьте эти файлы в коммит. Исходный HTML для локальной разработки находится в `dev.html`.

Адрес игры: <https://artemshlyakov.github.io/h_game/>.

## Управление и правила

- Мышь или палец: ведите ведьму влево и вправо.
- Клавиатура: стрелки ← → или A / D.
- Тыква +10, конфета +20, золотая тыква +50. Серия уловов увеличивает бонус.
- Череп и призрак отнимают жизнь. Раунд длится 60 секунд или пока не закончатся 3 жизни.
- При поимке полезных предметов воспроизводится `public/assets/catch.wav`; звук потери жизни остаётся прежним.
- На телефоне используется отдельное высокое игровое поле с полным пейзажем.

Рекорды в этом прототипе хранятся **только в текущем браузере**. Общий рейтинг и база данных будут добавлены после согласования механики и архитектуры.
