# Ловец тыкв

Прототип хэллоуинской веб-игры на **TypeScript, Phaser и Vite**.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173`). Сборка: `npm run build`.

## GitHub Pages

При каждом изменении ветки `main` workflow `.github/workflows/pages.yml` собирает игру и публикует содержимое `dist`. Для первоначального включения откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**. Адрес игры: <https://artemshlyakov.github.io/h_game/>.

## Управление и правила

- Мышь или палец: ведите ведьму влево и вправо.
- Клавиатура: стрелки ← → или A / D.
- Тыква +10, конфета +20, золотая тыква +50. Серия уловов увеличивает бонус.
- Череп и призрак отнимают жизнь. Раунд длится 60 секунд или пока не закончатся 3 жизни.

Рекорды в этом прототипе хранятся **только в текущем браузере**. Общий рейтинг и база данных будут добавлены после согласования механики и архитектуры.
